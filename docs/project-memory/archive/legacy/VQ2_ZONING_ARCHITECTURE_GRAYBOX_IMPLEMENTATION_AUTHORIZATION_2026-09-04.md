# VQ2 Zoning Architecture Graybox Implementation Authorization — 2026-09-04

> Status: USER AUTHORIZED CANDIDATE GRAYBOX IMPLEMENTATION / NOT FINAL LOCK
>
> Scope: Open20m candidate spatial zoning architecture. This authorizes implementation for Human Spatial / Feel review only. It does not lock final furniture, exact materials, final partition geometry, or production promotion.

## 1. Goal

The current Open20m layout has acceptable functional positions but still reads too much like one giant undivided room. The next pass should create distinct room-like territories while preserving overall openness, sightlines, and circulation.

Design principle:

- The room should behave as "rooms without full-height walls".
- Use differentiated architectural boundary methods rather than repeating the same screen everywhere.
- Preserve the 6m architectural shell while introducing lower human-scale spatial layers around roughly 2.6–3.0m where appropriate.

## 2. Authorized zoning architecture elements

### Experiment / Atelier — strong boundary

- Keep the experiment area anchored in the northwest corner.
- Add an incomplete L-shaped interior boundary using low cabinetry plus upper slats / translucent massing and/or a short return element.
- Keep a clear entrance opening of roughly 1.5–1.8m.
- Test a lightweight open overhead frame / portal at roughly 2.7–3.0m high to create a human-scale room-within-room feeling without a ceiling.
- Do not create a sealed laboratory or full-height walls.

### Living — medium boundary

- Keep the TV/sofa relationship.
- Add a low sofa-back console or similar architectural furniture edge behind the sofa.
- Test a lightweight open spatial frame / lighting-frame massing above the living island at a human-scale height if it does not visually cage the room.
- Do not add a screen wall around the living room.

### Window / Bar / Pantry — integrated architectural composition

- Treat pantry, low cabinetry, window, bar, and stools as one continuous "Window Room" composition rather than isolated objects.
- Use high-to-low cabinetry massing and the bar itself as the spatial boundary.
- Do not add a separate screen unless later Human review explicitly asks for one.

### Private Rest / Sleep — strong boundary

- Replace the single isolated privacy screen feeling with an L-shaped partial enclosure.
- Use headboard/storage massing plus a second partial screen or cabinet edge.
- Keep at least one corner fully open toward the larger room / Outside.
- Test an open overhead frame around roughly 2.5–2.8m high.
- Do not create a sealed bedroom.

### Dining / Observe — soft boundary

- Use rug/material/lighting center and furniture grouping only.
- No physical screen required.

### Retrieval — very light boundary

- Preserve operation, tether, Orb, landing, and carrying space.
- If needed, use only low equipment/storage massing or a subtle floor/portal cue toward the domestic side.
- Do not screen or enclose the Retrieval Station.

### Atlas — boundary by emptiness

- Do not add partitions around Atlas.
- Preserve negative space as its primary spatial distinction.

## 3. Non-negotiable preservation

Do not redesign or move without a hard conflict:

- Open20m floor and build grid
- current wall geometry/material direction
- Door / TV / Sofa / current basic living layout
- Atlas
- Retrieval Station
- current Window / Bar relationship
- current Experiment location
- current Sleep location
- Player / Camera / Lighting
- Production assets/scenes

## 4. Review criteria

Human review should focus on first-person perception, not only top-down geometry:

- Living should feel like a room despite no full-height wall.
- Entering Experiment should feel like crossing into a more focused work territory.
- Sleep should feel sheltered and private enough without becoming a closed bedroom.
- Window/Bar should read as one coherent architectural zone.
- Retrieval should reopen the room toward Outside.
- Atlas should remain spatially central through negative space.
