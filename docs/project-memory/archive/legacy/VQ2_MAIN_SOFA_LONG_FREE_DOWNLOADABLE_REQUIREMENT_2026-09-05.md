# VQ2 Main Sofa: Long + Actually Free/Downloadable Requirement

Date: 2026-09-05
Status: USER REQUIREMENT / AUTHORITATIVE FURNITURE PLACEMENT RULE

## User requirement

The Living main sofa must be a genuinely long sofa appropriate to the scale of the 20m x 20m room. It should not be replaced by a compact loveseat or short two-seater just because that asset is easy to download.

## Acquisition rule

For BlenderKit or similar sources, public listing text such as `FREE` is not sufficient by itself. Before import work, verify the current authenticated account can actually download the exact asset (`CAN_DOWNLOAD=True` or equivalent successful authorized endpoint). Do not pay for or bypass a restricted asset without explicit user authorization.

## Main-sofa sizing direction

- Prefer a real 3-4 seat sofa / long sofa.
- Practical target width: approximately 2.4m minimum, preferably around 2.6-3.2m if the real model and Living layout support it.
- Preserve real-world proportions; no non-uniform stretching to force grid fit.
- Measure the imported asset before final placement and report W x D x H, 0.5m hard-grid occupancy, usage clearance, orientation, and narrowest circulation width.
