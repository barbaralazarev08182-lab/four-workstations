# VQ2 Leisure / Memory / Media / Tabletop Play Ideas — 2026-09-06

Status: concept record only; not an implementation lock.

## 1. Player-created audio system

- The room should eventually support a player-created audio / speaker system.
- Audio hardware should be visually designed as a desirable residential object, not a generic UI appliance.
- Consider a wall-mounted record player / turntable concept, consistent with the previously discussed idea.
- Players should be able to play songs/music in the room.
- The audio system is part of habitation and room identity rather than a detached menu feature.

## 2. Camera / recording ecosystem

- Add player-usable camera and video-capable devices, inspired in spirit by contemporary consumer camera / DJI-like product families rather than copying a specific branded product.
- Recording should support multiple use cases:
  - photos of friends / social moments;
  - the star field and refuge sky;
  - memorable story beats;
  - discoveries and strange objects;
  - furniture layouts and changes to the room;
  - potentially video clips as a later extension.
- Photos should become persistent physical memories.
- Preferred long-term direction: photographs are physically developed / printed rather than instantly appearing as abstract inventory items.
- The development / printing process should be designed as a tactile progression loop so the resulting photo feels earned.
- Developed photos can be mounted / taped / framed on walls in the room.
- This can turn the room into an autobiographical record of the player's run and discoveries.
- Exact chemistry / darkroom / printer fiction is deferred for later design work.

## 3. Tabletop card-game activity

- Reserve room for a slightly larger table between the fishing area and the TV / sofa area.
- The table can support dining and general table actions, but a key leisure use is card games.
- One standard deck should be sufficient as the base physical object.
- Candidate rule sets can include:
  - Dou Dizhu;
  - Texas Hold'em;
  - additional card games later.
- This is not intended to replace the main mystery / discovery loop. It is a downtime / leisure layer that gives players reasons to remain in the refuge even when not progressing story content.
- Multiplayer/social possibilities are desirable, but exact networking / NPC implementation is deferred.

## 4. Design principle emerging from these ideas

The refuge should support three overlapping forms of non-mainline inhabitation:

1. **Contemplative:** fishing, music, watching the sky.
2. **Expressive / archival:** photography, room decoration, displaying developed photos.
3. **Social / playful:** card games, shared listening, shared viewing of photos and memories.

These systems should remain diegetic, physical, and room-based. They should reinforce the refuge as a home and memory container rather than becoming disconnected minigame menus.

## 5. Key integration opportunity

These leisure systems can connect back to the core loop `Inhabit -> Retrieve -> Inspect -> Place -> Observe -> Connect -> Reinterpret` without forcing themselves into every story beat:

- recovered media / records can become playable on the audio system;
- retrieved camera parts / lenses / film / print materials can unlock new recording capabilities;
- photographs can preserve evidence, relationships, changing sky states, room layouts, and story moments;
- card decks / card variants can be recovered artifacts or rewards;
- leisure objects can reveal subtle narrative information through repeated use.

The intended result is a game where the player has meaningful reasons to remain in the room between discoveries, not merely wait for the next objective.
