# VQ2 Interior Layout V2.1 — Domestic Completion Graybox Proposal — 2026-09-04

> Status: PROPOSAL / NOT YET USER-LOCKED
>
> Scope: Open20m candidate, after Interior Layout V2 graybox implementation and Human discussion.
>
> Purpose: use the remaining 20x20 space to complete the domestic program without diluting the Experiment / Retrieval gameplay structure or turning the room back into an office.

## 1. Current principle

The 20x20 room is large enough to support both high-end residential life and the required gameplay functions.

Do not respond to the remaining open floor by filling it with many small props. Prefer a small number of larger, coherent furniture islands and deliberately preserved negative space.

Current spatial anchors remain:

- west/south entrance;
- west-wall TV and floating living island;
- northwest Experiment / Atelier;
- north-right Window + Bar;
- central Atlas;
- east-side Retrieval;
- south/open edge as quiet Observe / Outside relationship.

## 2. Proposed missing domestic program

Add only the following as V2.1 graybox candidates:

### A. Private Rest / Sleep Island

Provisional area: southeast / south-east-of-center, away from the Retrieval operating envelope.

Working center: approximately X=5.3, Z=-5.6.

Suggested initial graybox:

- bed/daybed footprint about 2.1m x 2.2m;
- one low headboard/storage mass;
- one partial privacy screen, about 1.6-1.8m high;
- preserve open top and avoid creating a closed bedroom box.

This zone should feel more private than the living room but remain part of the open refuge.

### B. Compact Kitchen / Pantry Support for Window Bar

Do not build a full conventional kitchen island.

Use a compact support run adjacent to the north-wall bar/window zone.

Working candidate:

- 2.4-3.0m long cabinet/pantry run;
- about 0.6m deep;
- placed on the solid north-wall segment between Experiment and the Window, or immediately adjoining one end of the Bar where circulation remains clear.

Program can later support water, storage, refrigeration, small cooking, cups, food, and ordinary domestic use.

### C. Small Dining / Multipurpose Table

Do not reserve a large formal dining zone.

Candidate:

- round table diameter about 1.2-1.4m, or compact oval about 1.6-1.8m long;
- four chairs maximum in the first layout test;
- place south-central / south-west-of-center where it does not block Door -> Living, Work route, Atlas negative space, or Observe.

This is a domestic completeness object, not a visual hero.

### D. Domestic Storage

Avoid scattered cabinets.

Prefer one or two integrated storage masses:

- pantry/storage near the Window/Bar;
- private-rest storage/headboard near Sleep;
- Experiment keeps its own separate work storage.

The goal is to hide clutter so the room can remain visually calm.

## 3. Plants and cat

Do not create a dedicated Plant Zone or Cat Zone.

Future plants and cat-use locations should be distributed through the home, for example:

- one larger plant near Window/Bar;
- one smaller plant near Living;
- cat-compatible window/bar ledge;
- one cat rest point near sofa;
- one cat rest point near private sleep area.

For V2.1 graybox, only tiny locator proxies are needed if spatial validation requires them.

## 4. Furniture scale observation

The current 20m room makes ordinary residential furniture read smaller than expected.

Future art should likely use larger Italian-style furniture groupings rather than more individual pieces.

Working future scale direction:

- living sofa system may grow toward roughly 4.0-4.8m total width;
- living rug may grow toward roughly 5.0 x 4.5m;
- add at most one strong lounge chair rather than many small chairs.

Do not resize the current V2 graybox solely from this note unless specifically authorized.

## 5. Negative-space contract

Remaining empty floor is not a defect.

Preserve large negative space for:

- Atlas presence;
- Retrieval deployment and returned-object staging;
- player circulation;
- south/open-edge relationship to Outside;
- future construction/build-grid use;
- visual calm.

Working allocation intuition only, not a metric lock:

- roughly 40-45% domestic/furnishing;
- roughly 20-25% Experiment + Retrieval gameplay;
- roughly 30-35% circulation, Atlas clearance, open edge, and intentional negative space.

## 6. V2.1 implementation gate

If implemented, only add graybox proxies for:

1. Private Rest / Sleep Island;
2. Compact Kitchen / Pantry;
3. Small Dining / Multipurpose Table;
4. minimal distributed plant/cat location markers if useful.

Do not add final furniture assets, final materials, new lighting, sun, Outside sky, final Matter Bench art, gameplay systems, or production promotion.

After V2.1 graybox, require Human first-person review before treating exact coordinates or sizes as locked.
