# VQ2 First-Person Zoning Architecture Review — 2026-09-04

> Status: HUMAN FIRST-PERSON ARCHITECTURAL REVIEW
>
> Decision: underlying Interior Layout V2/V2.1 is retained; current zoning-frame language is NOT accepted as final spatial architecture.

## 1. What passes

- The underlying placement of Door, TV/Living, Experiment, Window/Bar, Sleep, Atlas, and Retrieval remains viable.
- Experiment is the strongest current zoning result. Its low cabinet + sparse vertical slats + partial return produces a readable threshold and begins to feel like entering an Atelier rather than crossing a debug zone.
- Retrieval should remain visually open; no tall partition is required.
- Atlas should continue to use negative space rather than physical borders.

## 2. What fails / needs revision

- The current Living and Sleep overhead Open Frames read too literally as wireframe/exhibition/booth structures in first-person views.
- Thin complete rectangular perimeter frames call attention to themselves and weaken the high-end residential character.
- The room still reads too much as one giant hall with furniture islands because several boundaries are either too thin, too detached, or too object-like rather than architectural.
- Window/Bar/Pantry composition is still visually weak as a coherent "Window Room" and needs a stronger architectural anchor rather than more small standalone boxes.

## 3. Revised direction

Do not change the accepted floor plan just to solve this.

Replace complete rectangular frame language with incomplete architectural cues:

- Living: prefer TV wall + larger rug + sofa-back console + one or two partial overhead/vertical cues; no complete cage-like frame.
- Experiment: keep the low cabinet/slat logic; reduce the overhead frame to a partial portal/beam if needed.
- Sleep: keep stronger L-shaped privacy massing, but reduce/remove the full overhead rectangle; use one partial portal, headboard/storage wall, and one side screen to create a nest-like room.
- Window Room: strengthen a tall-to-low cabinetry/architectural composition around Pantry -> Window -> Bar; avoid filling the entire north wall.
- Retrieval: remain open.
- Atlas: remain unbounded.

## 4. Review rule

The desired condition is:

- from far away, all zones still belong to one home;
- approaching a zone, its boundary becomes legible;
- entering it, human-scale enclosure is felt;
- no zone should look like a temporary trade-show booth or debug wireframe.

This decision supersedes any interpretation that the current Living/Sleep full Open Frames are visually accepted.
