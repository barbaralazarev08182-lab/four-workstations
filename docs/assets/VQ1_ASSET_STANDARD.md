# VQ1 资产规范 · VQ1 Asset Standard

> 适用于 VQ-1A Blender 管线与桌面端视觉样板阶段。
> 本规范是样板阶段的软限制，不追求最终极限压缩。

---

## 一、验收视口

| 视口 | 说明 |
|------|------|
| 最低验收 | 1280×720 |
| 主验收 | 1920×1080 |
| 桌面目标 | 浏览器稳定 60 FPS |
| 手机端 | 暂不作为验收目标，但不删除现有响应式代码 |

---

## 二、美术方向

**高级玩具屋 × 建筑模型 × 温柔生活游戏**

- 风格化模型 × 接近现实规律的光影
- 不追求写实 PBR，不追求高饱和塑料，不追求镜面展厅
- 不直接使用来源不同、风格不统一的模型
- 所有公开模型进入正式场景前必须经过 Blender 统一改造

---

## 三、资产质量门槛

### 先检查轮廓和比例，再做材质

- 关键边缘必须有合理倒角（Bevel）
- 软物体必须有体积起伏、压痕或软硬转折
- 不能只靠 roughness 冒充质感
- 玻璃、金属、木材、织物、塑料受光必须不同

### 资产进入正式场景前必须：

1. 在 Blender 中检查轮廓和比例
2. Apply Rotation / Scale
3. 检查法线方向
4. 检查 UV0 布局
5. 在 Blender 中使用 Principled BSDF 验收材质
6. 导出 GLB 后在 R3F 中再次验收
7. 在桌面端 1920×1080 验收视口下确认 60 FPS

---

## 四、初始预算（样板阶段软限制）

| 资产 | 预算 |
|------|------|
| 单套工位 | ≤ 25k triangles |
| 单张沙发 | ≤ 20k triangles |
| 肠粉 | ≤ 25k triangles |
| 单个人物 | ≤ 35k triangles |
| 单个主要资产材质槽 | 建议 1–3 个 |
| 代表资产纹理 | 优先 1K，核心近景允许 2K |
| 初始可见场景总量 | 约 400k triangles 内 |

**这些是初始预算，不要为了满足数字破坏轮廓。**

---

## 五、资产命名

- Blender 对象命名：`vq1_类别_名称`（例如 `vq1_chair_modern_arm`）
- GLB 文件名：`vq1-类别-名称.glb`（例如 `vq1-chair-modern-arm.glb`）
- 材质命名：`Mat_类别_名称`（例如 `Mat_Wood_Oak_Dark`）
- 纹理命名：`Tex_类别_名称_通道`（例如 `Tex_Wood_Oak_Dark_BaseColor`）
