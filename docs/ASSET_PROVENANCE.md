## 许可速查

| 许可 | 可否商用 | 是否需要署名 | 可否修改 | 可否再分发 |
|------|----------|--------------|----------|------------|
| CC0 | 是 | 否 | 是 | 是 |
| CC BY | 是 | **是** | 是 | 是 |
| CC BY-SA | 是 | **是** | 是 | 是（需同许可）|
| CC BY-NC | **否** | 是 | 是 | — |
| CC BY-ND | 是 | 是 | **否** | — |
| 自定义免费许可 | 看条款 | 看条款 | 看条款 | 看条款 |

**本项目最低要求**：CC0 或 CC BY。
署名要求：在 `ART_DIRECTION.md` 的致谢区或应用的"关于"页面中标注。
