## 总结：跨类别设计原则

1. **微缩世界的室内尺度** — 人物和家具的相对比例让人感觉"在看一个精心制作的模型"
2. **暖色 + 自然材质** — 木、布、陶、纸板的色彩和质感，拒绝冷金属和高光
3. **固定视角的构图完整性** — 每个主要视角都应像舞台布景一样"完整"
4. **低多边形作为风格选择** — 不是性能妥协，而是几何美学的刻意追求
5. **光照讲述时间和情绪** — 日/夜灯光循环不只是颜色切换，而是空间氛围的变化
6. **物品的"生活感"密度** — 有留白，有密集，但都没有杂乱
