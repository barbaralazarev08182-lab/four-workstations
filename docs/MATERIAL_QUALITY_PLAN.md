# 全场景材质质感审计与升级规划 · Material Quality Pass

> 目标：让不同材质对光的反应不同，而不是单纯换颜色。
> 保持「高级玩具屋 × 建筑模型 × 温柔生活游戏」。
> 约束：不追求写实贴图、不下载外部模型、不新增依赖。
> 本文为规划文档，不含代码补丁。

## 一、当前最缺质感的对象排名（按优先级）

| 排名 | 对象 | 当前状态 | 核心问题 |
|------|------|----------|----------|
| 1 | **窗户玻璃与窗框** | 玻璃 `#c2d0d6` / roughness 0.15 / opacity 0.22；窗框 `#e8e0d0` / roughness 0.85 | 玻璃读作"蓝色塑料"：有透明+低粗糙度，但**无反射、tint 过蓝**；窗框只是平涂暖白，无漆面/木质感 |
| 2 | **金属小部件** | 门把手 metalness 0.18 / roughness 0.55；MAT.metal metalness 0.35 | metalness 过低且**无 envMap**，金属不反光，读作"微亮塑料" |
| 3 | **肠粉（猫）** | catBody roughness 0.95 平铺 | 无绒毛/plush 感，蓝灰毛色平铺，英短的"绒"读不出来 |
| 4 | **沙发 / 猫窝 / 毛毯 / 软装** | fabric / fabricSoft roughness 0.98 平铺 | 无织物 sheen，无软硬对比，布料和木头受光几乎一样 |
| 5 | **人物** | 皮肤/头发/衣服 roughness 全在 0.86–0.96 | 皮肤、头发、衣服受光几乎相同，无软硬/光泽分层 |
| 6 | **工位桌椅** | woodTop roughness 0.78；塑料椅 roughness 0.55 | 木桌无漆面/木纹感，塑料椅与木桌光泽差异不足 |
| 7 | **餐桌 / 咖啡机 / 杯具** | 杯子 roughness 0.86（应为陶瓷）；咖啡机平铺塑料 | 陶瓷杯读作哑光塑料，无釉面感 |
| 8 | **墙 / 地板 / 门** | 地板已有 3 色木板循环；墙 roughness 0.96 | 基础尚可，仅墙面过于平、门平涂 |

**判断逻辑**：排名按"当前状态与目标的落差 × 视觉显著度"。玻璃是**唯一读作完全错误材质**的对象（塑料感），且是用户明确点名；金属是"反光"这一明确诉求的直接落点；肠粉是英雄角色；软装与人物是大面积/焦点对象。

## 二、逐类分析"为什么没有质感"

### 窗户玻璃与窗框
- **形体**：玻璃是单平面薄片，无厚度，无玻璃边缘——形体仍像 blockout。
- **材质**：`roughness 0.15 + opacity 0.22 + 灰蓝 tint`，但**没有任何反射**。低粗糙度+无反射=塑料片。玻璃的"玻璃感"来自**反射+高光+极低饱和 tint**，三者缺一。
- **光打上去**：光穿过玻璃无折射、无高光点，读不出材质。
- **窗框**：平涂暖白 roughness 0.85，无漆面感，与墙几乎同质。

### 金属小部件
- **材质**：metalness 0.18–0.35 过低，且**场景无 envMap**。金属的"反光"本质是反射环境；没有 envMap 时 metalness 越高越黑。当前金属既不反光也不亮，读作"微亮塑料"。
- **主次**：金属只出现在门把手/灯杆等小件，本应"少而精"，但当前连"金属感"都没有。

### 肠粉（猫）
- **材质**：catBody roughness 0.95 平铺，**无 sheen**。英短蓝灰毛的"绒"感来自高粗糙度+柔和 sheen（绒毛逆光泛光）。当前只有平铺色。
- **形体**：形体比例已较好（矮壮、圆脸、厚脸颊），但脸部轮廓（脸颊与口鼻的过渡）仍偏"球体拼接"。
- **软硬对比**：猫（软）与地板/家具（硬）无材质对比。

### 沙发 / 猫窝 / 毛毯 / 软装
- **材质**：fabric roughness 0.98 平铺，**无 sheen**。织物的"布感"来自柔和 sheen（纤维泛光）。当前与木头受光几乎一样。
- **软硬对比**：沙发（软）与木桌（硬）无光泽差异；猫窝无"绒"感。
- **厚度**：坐垫 RoundedBox 已有圆角，但"蓬松"感不足。

### 人物
- **材质**：皮肤/头发/衣服 roughness 全在 0.86–0.96，**三者受光几乎相同**。皮肤应比头发略"润"（低粗糙度+微暖），头发应最哑光，衣服应为织物。
- **软硬对比**：皮肤（软）与衣服（布）无对比。
- **形体**：低多边形风格正确，但皮肤无"肉感"（无近似 SSS 的暖色+中粗糙度）。

### 工位桌椅
- **材质**：woodTop roughness 0.78 平铺，**无漆面感**。上漆家具木应有轻微 clearcoat sheen。塑料椅 roughness 0.55 与木桌光泽差异不足。
- **厚度**：桌面厚度 0.26 已可信，但桌腿与桌面连接处无过渡。

### 餐桌 / 咖啡机 / 杯具
- **陶瓷杯**：roughness 0.86 读作哑光塑料，应为 roughness 0.3–0.45 + 轻微 clearcoat 的釉面。
- **咖啡机**：平铺塑料，机身/出液口/显示区光泽无分层。

### 墙 / 地板 / 门
- **墙**：roughness 0.96 平涂，无乳胶漆的微妙起伏（可接受，优先级最低）。
- **地板**：已有 3 色木板循环，较好；可加轻微 clearcoat 表达"打蜡木"。
- **门**：平涂，无漆面感。

## 三、材质分类系统建议

> 全部基于 three.js 内置材质（MeshStandardMaterial / MeshPhysicalMaterial），**不新增依赖**。
> clearcoat / sheen 需 MeshPhysicalMaterial（three 内置，非新依赖）。
> 金属/玻璃的反射需要 envMap，推荐用 drei `<Environment>` + Lightformer **程序化生成**（drei 已是依赖，无下载）。

| 类别 | 视觉目标 | 颜色方向 | roughness | metalness | transparent/opacity | clearcoat/sheen | 应用对象 |
|------|----------|----------|-----------|-----------|---------------------|-----------------|----------|
| **wall** | 哑光乳胶漆，柔和不反光 | 暖米白 `#efe7d7` / 夜 `#474c4b` | 0.95–1.0 | 0 | 否 | 无 | 四面墙段 |
| **floorWood** | 打蜡实木地板，微妙光泽 | 暖木 3 色循环（现有） | 0.65–0.8 | 0 | 否 | clearcoat 0.15–0.3, ccRoughness 0.6 | 地板木板 |
| **furnitureWood** | 上漆家具木，比地板更润 | 桌面 `#c9a173` / 腿 `#9c7856` | 桌面 0.55–0.7 / 腿 0.7–0.85 | 0 | 否 | clearcoat 0.2–0.4, ccRoughness 0.5 | 桌面、会议/餐桌、桌腿、椅木件、边桌 |
| **fabric** | 编织布料，哑光纤维感 | 低饱和绿 `#8a9d8a` / `#9aad98` | 0.95–1.0 | 0 | 否 | **sheen 0.3–0.6**, sheenRoughness 0.8, sheenColor 略亮 | 沙发主体/靠背/坐垫、椅坐垫/椅背 |
| **plush / softFabric** | 绒毛/天鹅绒，吸光+逆光泛光 | 蓝灰 `#8b95a0` / `#a7b0ba` | 1.0 | 0 | 否 | **sheen 0.6–1.0**, sheenRoughness 1.0, sheenColor 亮一档 | 猫窝、内垫、毛毯、猫身体（绒毛近似） |
| **plastic** | 光滑塑料，与木/布明确分离 | 深灰 `#4a514f` / `#5c6361` | 0.35–0.55 | 0–0.05 | 否 | clearcoat 0.3（可选） | 显示器框、椅座、咖啡机、键盘 |
| **metal** | 反光但非镜面的拉丝金属 | 黄铜 `#b3a586` / 中性 `#a8a8a8` | 0.25–0.4 | **0.7–0.9** | 否 | 无 | 门把手、灯金属件、椅金属腿（少量） |
| **glass** | 像玻璃：透明+微反射+极淡冷调 | 近透 `#dfe8ea` / 夜 `#3a4a55` | **0.05–0.12** | 0.1–0.2 | **是, opacity 0.12–0.22** | 无（或 transmission 0.85 高级选项） | 窗户玻璃 |
| **screen** | 深色光泽屏幕（关闭态），微反射 | 深灰黑 `#2e3436` | 0.15–0.3 | 0.1–0.2 | 否 | clearcoat 0.5, ccRoughness 0.1 | 显示器屏、会议屏、咖啡机显示 |
| **ceramic** | 釉面陶瓷，光滑微亮 | 暖白 `#f1e8d7` / 食盆 `#8a6a4a` | 0.25–0.45 | 0 | 否 | clearcoat 0.4, ccRoughness 0.3 | 杯子、食盆 |
| **paper** | 哑光纸张 | 暖白 `#f0e8d6` | 0.9–1.0 | 0 | 否 | 无 | 会议桌纸张、文件 |

**关键说明**：
- **metal 必须配 envMap**：无 envMap 时 metalness>0.5 会发黑。用 drei `<Environment resolution={64}>` + Lightformer 生成简单程序化环境（暖顶光+冷侧光），一次 PMREM，开销小。
- **glass 的"玻璃感"三要素**：低粗糙度（高光锐）+ 微反射（envMap）+ 极低饱和 tint。当前"蓝塑料"= tint 太蓝 + 无反射 + opacity 居中。
- **sheen 是织物/绒毛的灵魂**：MeshPhysicalMaterial.sheen 给出纤维逆光泛光，是"布像布、绒像绒"的关键，three 内置无新依赖。

## 四、最应该优先精修的 5 个对象

按"价值/成本"排序，不是"都要改"：

1. **窗户玻璃**
   唯一读作**完全错误材质**的对象（蓝色塑料），用户明确点名。修复路径清晰（降 tint+降 opacity+加 envMap 反射），且 envMap 是玻璃与金属的**共享基础设施**，一次投入两处受益。窗是画面视觉焦点（光从窗来），玻璃质感直接决定"室内自然光"的可信度。

2. **金属小部件 + 程序化 envMap**
   "金属能反射光"是明确诉求。金属件虽小（门把手/灯杆），但"金属反光"是**品质感的最强信号**——观众对金属反光极其敏感。且 envMap 建立后玻璃同步受益。成本低、信号强。

3. **肠粉（英短绒毛）**
   英雄角色，出场率最高。英短蓝灰"绒"感是角色魅力核心。用 sheen（plush 类）即可大幅提升，无需改形体。猫是"温柔生活游戏"的情感锚点，质感提升的感知价值最高。

4. **沙发 / 猫窝 / 毛毯（软装家族）**
   大面积软装当前与木头受光相同，是"软硬对比缺失"的最大来源。用 sheen（fabric/plush 类）一次覆盖沙发+猫窝+坐垫+椅垫，面积大、一次改动多处受益。

5. **人物皮肤 / 头发 / 衣服**
   人物是焦点，但皮肤/头发/衣服三者 roughness 几乎相同（0.86–0.96），无材质分层。分层后（皮肤微润、头发最哑光、衣服织物 sheen）人物"活"起来。成本中等（4 个角色共用材质参数），感知价值高。

**不在此列的**：墙/地板/门（基础尚可，留到 1D-0A 顺手处理）、餐桌/咖啡机（留到 1D-0D）。

## 五、质感重构路线图（4 个小阶段）

### Phase 1D-0A：材质系统与场景硬装质感
- **目标**：建立统一材质分类系统（MAT 升级为分类系统）+ 程序化 envMap 基础设施 + 玻璃/金属/墙/地板/门质感。
- **主要修改文件**：
  - `components/office-3d/scene-config.ts`（MAT 升级为分类材质系统，含 clearcoat/sheen 参数）
  - `components/office-3d/OfficeWorld.tsx`（墙/地板/门/窗玻璃/窗框材质 + `<Environment>`+Lightformer）
  - `components/office-3d/OfficeAmenities.tsx`（门金属把手）
- **不允许修改**：相机、HUD、Supabase、人物、肠粉、家具几何、灯光强度（仅可加 envMap，不调 1B-2 灯光参数）。
- **完成视觉标准**：
  - 玻璃读作玻璃（透明+微反射+无蓝塑料感），能透视看到窗外天空色块。
  - 门把手/灯金属件有可辨反光，但不镜面。
  - 地板有打蜡木微光泽，墙哑光。
  - 灰度下玻璃/金属/墙/地板可辨。

### Phase 1D-0B：人物质感与服装
- **目标**：皮肤/头发/衣服材质分层，人物"活"起来。
- **主要修改文件**：
  - `components/office-3d/AnimatedLowPolyCharacter.tsx`（皮肤/头发/衣服/腿/鞋材质分层）
  - `components/office-3d/scene-config.ts`（人物材质参数入 MAT 分类）
- **不允许修改**：人物形体/比例/动画/坐标、相机、HUD、Supabase。
- **完成视觉标准**：
  - 皮肤微润（roughness ~0.6 + 暖色），头发最哑光（roughness ~0.95），衣服织物 sheen。
  - 三者受光可辨差异；灰度下皮肤比头发亮。
  - 4 个角色服装色保持现有 accent 体系。

### Phase 1D-0C：肠粉与猫区软装
- **目标**：肠粉英短绒毛感 + 猫窝/内垫/毛毯 plush 感。
- **主要修改文件**：
  - `components/office-3d/ChangFenCat.tsx`（猫身体/脸颊/耳/尾绒毛 sheen）
  - `components/office-3d/OfficeWorld.tsx`（猫窝/内垫 plush 材质）
  - `components/office-3d/scene-config.ts`（plush 类材质参数）
- **不允许修改**：猫的形体比例/动画/坐标、猫区位置、相机、HUD、Supabase。
- **完成视觉标准**：
  - 猫身体读出"绒"感（sheen 逆光泛光），蓝灰毛色不平板。
  - 猫窝/内垫有绒毛吸光感，与木地板形成软硬对比。
  - 金眼保持不发光但稍光滑。

### Phase 1D-0D：主要家具精修与小物件统一
- **目标**：桌面漆面感、椅塑料感、陶瓷杯釉面、屏幕光泽、小物件材质统一到分类系统。
- **主要修改文件**：
  - `components/office-3d/LowPolyWorkstation.tsx`（桌面 clearcoat、显示器框塑料、屏幕光泽）
  - `components/office-3d/OfficeAmenities.tsx`（会议/餐桌漆面、咖啡机分层、杯具陶瓷、纸张）
  - `components/office-3d/scene-config.ts`（furnitureWood/plastic/screen/ceramic/paper 参数）
- **不允许修改**：家具几何/坐标、相机、HUD、Supabase、灯光。
- **完成视觉标准**：
  - 桌面有上漆木微光泽，与哑光墙面可辨。
  - 显示器屏深色光泽（关闭态），不发光。
  - 杯子读作陶瓷（釉面），与塑料框可辨。
  - 灰度下木/塑料/陶瓷/纸可辨。

## 六、重点对象单独建议

### 1. 窗户玻璃
- **当前问题**：`roughness 0.15 + opacity 0.22 + 灰蓝 tint + 无反射` = 蓝色塑料。
- **建议**：
  - roughness 降到 **0.05–0.12**（高光锐利）。
  - opacity 降到 **0.12–0.22**（更通透）。
  - tint 改为**极淡冷调**（`#dfe8ea`，几乎无色，仅一丝冷），**不要明显蓝**。
  - **加 envMap 反射**（1D-0A 的程序化 envMap）——这是"像玻璃"的决定因素。
  - 可选高级：MeshPhysicalMaterial `transmission 0.85 + ior 1.5`（真实折射，较重，作为可选）。
  - 保持 `depthWrite={false}` 避免透明排序问题。
- **夜玻璃**：`#3a4a55` 更暗、opacity 略升（0.25），反射更明显（夜景玻璃反光更强）。

### 2. 金属小部件
- **当前问题**：metalness 0.18–0.35 + 无 envMap = 微亮塑料。
- **建议**：
  - metalness 提到 **0.7–0.9**，roughness **0.25–0.4**（拉丝感）。
  - **必须配 envMap**（否则发黑）。用 drei `<Environment resolution={64}>` + Lightformer（暖顶光+冷侧光）。
  - **克制使用**：只用于门把手、灯金属件、椅金属腿等小件，**不大面积使用**。
  - 黄铜 `#b3a586`（暖）或中性 `#a8a8a8`，避免亮铬。

### 3. 沙发 / 猫窝 / 毛毯 / 软装
- **当前问题**：fabric roughness 0.98 平铺，无 sheen，无软硬对比。
- **建议**：
  - 用 MeshPhysicalMaterial **sheen 0.3–0.6**（fabric）/ **0.6–1.0**（plush），sheenRoughness 0.8–1.0，sheenColor 比底色亮一档。
  - 沙发主体/靠背用 fabric，坐垫/猫窝/内垫用 plush。
  - 保持 roughness 0.95–1.0（哑光），sheen 提供纤维泛光。
  - 与木桌形成软硬对比（木 clearcoat 微亮 vs 布哑光 sheen）。

### 4. 人物皮肤 / 头发 / 布料
- **当前问题**：皮肤/头发/衣服 roughness 全 0.86–0.96，无分层。
- **建议**：
  - **皮肤**：roughness **0.55–0.65**（微润），暖色（现有 SKIN_TONES），可加极轻微 emissive（0.03 暖色）近似 SSS"肉感"。
  - **头发**：roughness **0.9–0.95**（最哑光），现有 HAIR_COLORS。
  - **衣服**：织物 sheen 0.3–0.5（accent 色），roughness 0.9。
  - 腿/鞋：裤子 roughness 0.9（布），鞋 roughness 0.5（微亮）。
  - 三者受光分层：皮肤最润、头发最哑光、衣服织物泛光。

### 5. 肠粉（英短蓝灰毛色与脸部轮廓）
- **当前问题**：catBody roughness 0.95 平铺，无绒毛感；脸部偏球体拼接。
- **建议**：
  - **身体/脸颊/耳/尾**：plush 类，**sheen 0.6–1.0**，sheenRoughness 1.0，sheenColor 比蓝灰亮一档（逆光泛光=绒毛感）。
  - 蓝灰主色保持 `#8b95a2`（暖蓝灰），脸颊 `#9ba5b1` 略浅。
  - **金眼**：保持不发光，roughness 0.4（稍光滑），瞳孔深色。
  - **脸部轮廓**：当前脸颊+口鼻球体拼接已可，质感提升后"球体感"会弱化（sheen 柔化边缘）。如需进一步优化属形体范畴（1D-0C 不做，留后续）。

## 七、可行性边界

### 可在"不加贴图、不加依赖"前提下做到
- **roughness / metalness 分层**（MeshStandardMaterial 参数）——所有材质的基础区分。
- **clearcoat / sheen**（MeshPhysicalMaterial，three 内置，**非新依赖**）——漆面木、釉面陶瓷、织物/绒毛 sheen。
- **玻璃透明 + 低粗糙度 + 极淡 tint + depthWrite false**——玻璃基础。
- **程序化 envMap**（drei `<Environment>` + Lightformer，drei 已是依赖，**无下载**）——金属/玻璃反射。
- **颜色分层**（现有地板 3 色循环可扩展到墙/家具）。

### 只能做到"风格化近似"
- **真实玻璃折射**：MeshPhysicalMaterial `transmission` 可做但较重；风格化近似=opacity+反射+低 tint。
- **真实毛发/fur**：无毛发模拟，用 sheen+颜色分层近似"绒毛感"。
- **真实木纹**：无贴图无木纹，用颜色循环+clearcoat 光泽近似"上漆木"。
- **真实皮肤 SSS**：无次表面散射，用暖色+中粗糙度+极轻 emissive 近似"肉感"。

### 需要通过形体优化（而非仅材质参数）
- **倒角/圆角**：已用 RoundedBox，可进一步细化（桌面边缘、椅背）。
- **厚度可信度**：桌面/椅背/坐垫的厚度与过渡（当前基本可信）。
- **轮廓精修**：猫脸部（脸颊与口鼻过渡）、人物剪影——属形体范畴，非材质能解决。
- **坐垫蓬松感**：当前 RoundedBox 圆角不足表达"蓬松"，需更圆的几何（留后续形体阶段）。
